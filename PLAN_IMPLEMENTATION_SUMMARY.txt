================================================================================
						   HTTP STATUS CODES
================================================================================

200 OK
  ├─ File found
  ├─ Withdrawal request exists
  └─ Returns complete WithdrawalDetailsDto

400 Bad Request
  ├─ FileId is null or empty
  └─ Returns error message

404 Not Found
  ├─ File doesn't exist, OR
  ├─ No withdrawal request for file, OR
  ├─ Missing application history, OR
  └─ Missing application info

500 Internal Server Error
  └─ Only for unexpected errors (should not occur with this implementation)
